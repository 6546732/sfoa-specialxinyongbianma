# 内部编码预览与依据

联网结果优先采用全名完全匹配、有来源、校验位通过的官方信用代码。否则显示内部编码预览区。

预览区显示采用地址、行政区划、行业或军事类别、军种、当前可用流水号、编码主体及校验位。军种以规则计算为准：空军为03，军事医疗为WH；AI自由文本里的数字不是编码依据。

未匹配的候选不会自动写入，也不会默认用于编码。用户核对上方资料后，可勾选人工确认再预览，仅允许用于内部编码和补空字段，不能绕过官方代码全名匹配条件。修改资料后确认和预览失效，须重新核对。

只知道“军队医院、空军”仍不足以生成：还需要确认国家、省、市以确定行政区划。界面显示缺失项或具体规则错误，不使用占位码。

预览不保留流水号；其他用户可能同时取号，所以正式保存结果可能与预览不同。确认生成时使用原有事务锁定取号机制。

验证：36项Apex测试通过，包括旧名称空军医院资料确认、预览不写客户及不消耗序列、最终生成与预览一致并只递增一次。另通过前端状态回归脚本。未执行真实客户数据修改或浏览器端到端测试。
